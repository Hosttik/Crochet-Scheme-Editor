# v1.13.0 — Crochet Row Boundaries

This release makes crochet row starts and closures explicit document semantics.

- Starting chains may optionally count as the first logical stitch of a row. A counted starting-chain boundary contributes exactly one stitch to the written row total without creating a fake canvas element or topology node.
- Rows may record how many base stitches are skipped before the first worked stitch.
- Joined rounds may close with a slip stitch either into the first worked stitch or into the top of the starting chain.
- Written RU/EN instructions distinguish the number of worked stitch elements from the logical row total when those values differ.
- The selected-row overlay exposes counted starting chains, skipped stitches and the exact closure target.
- Project schema v16 persists these boundary fields while v1–v15 projects remain loadable with their existing geometry and topology unchanged.

Release verification requires strict TypeScript, the complete Vitest suite, the production Vite build, Chromium E2E flows and the GitHub Pages smoke check to pass before merge.
