# v1.15.0 — Lasso Selection

This release completes the original interaction backlog with free-form lasso selection.

- Draw an arbitrary polygon directly on the canvas to select stitch elements.
- Selection uses stitch semantic centers for predictable inclusion.
- Shift-lasso adds to the current selection.
- Alt-lasso subtracts from the current selection.
- Grouped stitches expand as one authoring object.
- Parametric rows expand to the whole row using the existing semantic selection rules.
- L toggles the lasso tool; Escape returns to Select.
- Space + drag remains available as temporary pan while the lasso tool is active.

Release verification requires strict TypeScript, the complete Vitest suite, production build, Chromium E2E and GitHub Pages deployment before release is considered complete.
