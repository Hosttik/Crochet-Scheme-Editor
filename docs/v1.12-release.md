# v1.12.0 — Pattern Authoring Pass

This release completes three authoring workflows requested during usability review:

- **Guide Lock:** Arc, Line, Curve, Rectangular Grid and Radial Grid guides remain selectable while locked, but direct manipulation and numeric geometry editing are disabled until unlocked.
- **Row-number annotations:** independent red-dot row markers support automatic first-gap numbering, manual renumbering, drag, visibility and lock. They persist through autosave/JSON and are included in SVG export.
- **Automatic legend:** the canvas and SVG export derive a localized abbreviation/name legend from the visible stitch symbols actually used in the pattern. Legend visibility is persisted.

The project format is **schema v15**. Runtime migration remains supported for schema v1–v14.

Release verification covers strict TypeScript, Vitest, production build, Chromium E2E workflows and the published GitHub Pages endpoint.
